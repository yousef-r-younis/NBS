Final Assessment 🏆

Grades 7-8 Comprehensive Exam

Session 10: Test Your Technical Knowledge

Assessment Overview 📋

This comprehensive assessment tests your understanding across four areas: Python programming, AI fundamentals, web development, and professional skills.

Assessment Structure:

  • Part 1 - Python Coding (25%): Write and debug Python code
  • Part 2 - AI Knowledge (25%): Essay questions and conceptual understanding
  • Part 3 - Web Development (25%): Build an HTML/CSS webpage
  • Part 4 - Professional Document (25%): Create a formatted research paper
  • Total: 100 points

Part 1: Python Programming Test 🐍

Demonstrate your coding skills with real Python problems.

Section A: Code Reading (5 points)

Read the code below and explain what it does:

for i in range(1, 6):
  print(i * 2)

Question: What is printed? What if we change range(1, 6) to range(5, 10)?

Part 1 Continued: Python Coding 🐍

Section B: Code Writing (10 points)

Write a Python program that:

  1. Asks user for their age
  2. Uses if/elif/else to respond:
    • If age < 13: print "You're too young"
    • Elif age < 18: print "You're a teen"
    • Else: print "You're an adult"

Section C: Debugging (10 points)

Find and fix the bugs in this code:

name = input("What's your name")
age = input("How old are you")
age = age + 10
print("In 10 years, you'll be " + age)

Part 2: AI Knowledge Test 🤖

Answer essay questions demonstrating deep understanding of AI concepts.

Essay Questions (25 points total):

  1. (8 pts) "Explain how neural networks learn. Use the analogy of learning to ride a bike, then connect it to how weights change during training."
  2. (8 pts) "Compare and contrast supervised vs unsupervised machine learning. Give a real-world example of each."
  3. (9 pts) "Explain the Amazon hiring AI bias case. Why did it happen? What were the consequences? How could it have been prevented?"

Part 3: Web Development Project 🌐

Create a single-page website about any AI application (healthcare, transportation, education, etc.).

Requirements (25 points):

  • HTML Structure (5 pts): Valid HTML with proper semantic tags
  • Content (5 pts): 3-4 paragraphs explaining your chosen AI application
  • Elements (5 pts): At least 1 image, 1 bulleted list, 1 link to external resource
  • CSS Styling (5 pts): Custom colors, fonts, padding/margins, hover effects
  • Responsiveness (5 pts): Works on mobile and desktop

Part 4: Research Paper Project 📄

Create a professionally formatted research paper on an AI topic from Sessions 1-9.

Paper Requirements (25 points):

  • Title page: Proper formatting with title, author, date, school
  • Heading structure: Use Heading 1/2 styles (Introduction, Body, Conclusion)
  • Length: 2-3 pages double-spaced
  • Citations: At least 3 sources in MLA format
  • Bibliography: Auto-generated from citations
  • Page numbers: Proper academic format
  • Table of Contents: Auto-generated from headings

Topic Ideas for Research Paper 💡

Choose One:

  • "How Neural Networks Revolutionized AI"
  • "AI Bias: The Problem and Solutions"
  • "Machine Learning Applications in Healthcare"
  • "The Future of Autonomous Vehicles"
  • "AI and Job Displacement: What's Coming?"
  • "How Search Engines Rank Information"
  • "Ethical AI: Responsibility and Fairness"
  • "AI in Education: Personalized Learning"

Test-Taking Tips 💡

For Python Section:

  • Read code carefully line by line
  • Test your code in an online editor first
  • Check for off-by-one errors in loops
  • Verify indentation is correct

For Essays:

  • Use specific examples from the course
  • Explain the "why" not just the "what"
  • Connect concepts together

Test-Taking Tips Continued 💡

For Web Development:

  • Test your HTML/CSS in browser before submitting
  • Use inspector (F12) to debug styling
  • Mobile test: view on phone or use browser DevTools

For Research Paper:

  • Use Word styles (don't manually format)
  • Cite as you write (don't add citations at end)
  • Spell-check before submitting
  • Have someone read it for clarity
